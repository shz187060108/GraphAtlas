# Staged experiment plan

The synthetic screening preset contains 90 jobs; confirmatory contains 240. Real stage-one screening contains 120 jobs; confirmatory contains 280. Screening is used to detect implementation or capacity failures before ten-seed confirmatory runs.

Coordinate-only tests coordinate invariance, Mixed-metric tests varying curvature and local metric recovery, and Boundary-stress tests cross-chart messaging. Synthetic diagnostics do not control early stopping. Expansion is permitted only after the configured scientific and submission-readiness gates are evaluated on genuine run-level results.

No published aggregate is treated as a seed-level observation or used in a paired test.
