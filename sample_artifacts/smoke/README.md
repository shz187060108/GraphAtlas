# Smoke diagnostic artifacts

These files come from the completed 24-run software smoke preset and the exact packaged source hash recorded in `outputs/final_validation.json`.

They validate the implementation and the coordinate-invariance mechanism. They are not submission results. Full GraphAtlas reaches nonlinear coordinate-intervention error near numerical precision, while no-transport and free-transition variants are roughly four orders of magnitude worse. Boundary-node and predictive-gain gates do not pass in this smoke run, so the package does not claim predictive superiority.
